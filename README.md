## Português

[svg](https://github.com/diogo-root/TodoList/tree/newfeature#portugu%C3%AAs)

Lista de tarefas feita com HTML, CSS e JavaScript.

### Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Excluir tarefas
- Excluir todas as tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas por status
- Exibir todas as tarefas
- Exibir tarefas pendentes
- Exibir tarefas concluídas
- Registrar a data de criação da tarefa
- Registrar a hora de criação da tarefa
- Salvar tarefas no LocalStorage

Projeto desenvolvido para praticar JavaScript, DOM, LocalStorage, manipulação de arrays e filtros de dados.

## Italiano

[svg](https://github.com/diogo-root/TodoList/tree/newfeature#italiano)

Lista di attività realizzata con HTML, CSS e JavaScript.

### Funzionalità

- Aggiungere attività
- Modificare attività
- Eliminare attività
- Eliminare tutte le attività
- Segnare le attività come completate
- Filtrare le attività in base allo stato
- Visualizzare tutte le attività
- Visualizzare le attività in sospeso
- Visualizzare le attività completate
- Registrare la data di creazione dell'attività
- Registrare l'ora di creazione dell'attività
- Salvare le attività nel LocalStorage

Progetto sviluppato per esercitarmi con JavaScript, DOM, LocalStorage, manipolazione degli array e filtraggio dei dati.
