
# TodoList

## Português

Lista de tarefas feita com HTML, CSS e JavaScript.

Funcionalidades:

* Adicionar tarefas
* Editar tarefas
* Excluir tarefas
* Marcar como concluída
* Salvar tarefas no LocalStorage

Projeto desenvolvido para praticar JavaScript, DOM e LocalStorage.
